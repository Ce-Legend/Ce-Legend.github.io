# Ce Legend

个人网站 v0.2。

定位：不是正式求职官网，也不是简历美化版，而是一个长期更新的个人基地，连接作品集、GitHub、笔记、个人说明书和正式简历。

公网地址：

```text
https://ce-legend.github.io/
```

## 本地运行

```bash
npm install
npm run dev
```

## 部署

推送到 `main` 后，GitHub Actions 自动构建并发布到 GitHub Pages。

## 当前结构

- 首页：我的长期复利果园。
- 果园地图：已结果的树、正在生长的树、未来树苗区。
- 果园札记：文章、笔记、复盘和表达入口。
- 和时间做朋友：长期主义、复利、复杂系统和人生时间轴。
- 个人说明书：真实状态、协作方式和长期方向。
- 简历：后续连接产品岗正式简历 PDF。
